### 一、修正 provider（`src/providers/ddbProvider.ts`）

测试驱动暴露并修复了 3 个真实问题：

1. **sort key 的 `!=`/`IN`/`!IN`/OR 必须抛异常**（新增逻辑）
   - DynamoDB 的 `KeyConditionExpression` 只支持 sort key 的 `=`/`>`/`>=`/`<`/`<=`，不支持 `<>`；
   - 而 `FilterExpression` **不允许**包含 sort key 属性。
   - 因此 sort key 取反/集合/OR 无法表达，现在明确抛异常 `sort key ... cannot be negated or OR-ed`。

2. **partition key 值为 null/undefined 抛异常**（新增判断）
   - `pk = NULL` 不是合法的 key condition。

3. **null 语义回退为 `attribute_not_exists`/`attribute_exists`**
   - 我最初尝试用 `attribute_type(x, 'NULL')` 区分"NULL 类型"和"属性不存在"，但 `NULL` 是 DynamoDB 保留关键字（`attribute_type` 也不接受带引号的字符串字面量），无法正确表达。
   - 按你的提示「null 和 undefined 同等视为空」，回退为统一用 `attribute_not_exists`/`attribute_exists`。
